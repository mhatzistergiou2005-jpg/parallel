# PARALLEL

PARALLEL is a career discovery application that helps users explore their interests, identify suitable career paths, map skills, and create a practical roadmap for growth.

## Live application

[Open PARALLEL](https://mhatzistergiou2005-jpg.github.io/parallel/)

## Files

- `index.html` — application structure
- `style.css` — main styles
- `overrides.css` — additional style overrides
- `script.js` — application logic and interactions
